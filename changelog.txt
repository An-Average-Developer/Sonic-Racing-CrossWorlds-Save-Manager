2.0.0
## Additions
- Added a Manual Update option as a fallback for when the automatic updater doesn't detect or install a new version
- Added Discord Rich Presence, showing your current activity in the app on your Discord profile
- Added a Report a Bug tab to send bug reports directly from the app, with Discord account verification and optional screenshots
- Added an Auto-Attach toggle to the Memory Editor, with a manual process picker for when the game isn't detected automatically
- Added an Add to Steam tab to add this app as a non-Steam game shortcut, complete with its own icon and library artwork

## Bug Fixes
- The app now requires administrator privileges to run, needed for reliable memory access
