2.1.0
## Additions
- Added seasonal themes (Summer, Halloween and Christmas), with animated backgrounds and seasonal colors
- Added a Settings button in the header to pick the season theme (Default, Classic, Summer, Halloween or Christmas)

## Changes
- Replaced the ticket pointer system with a step-by-step Find Tickets guide that searches the game's memory for your ticket amount, so tickets can be found reliably after game updates
- Renamed the Cheat Menu tab to Tickets Menu

## Bug Fixes
- Updated the Freeze, Multiply and x500 ticket patches for the latest game version (1.4.3)
- Fixed the Reports and Steam tabs being misaligned compared to the other tabs
